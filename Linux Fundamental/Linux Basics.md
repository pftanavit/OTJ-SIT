## What the Colors Mean?

The colors in terminal are a visual code to help instantly spot what kind of file you are looking at. 
The standard Linux setups use these color rules:

* **Dark Blue**: Directory / Folder
  
  * Ex. `app`,`logs`,`scripts`
  
* **Green**: Executable File / Script

  * Ex. `app.sh`, `deploy.sh` (files you have permission to run)
  
* **Cyan (Light Blue)**: Symbolic Link
  
  * A shortcut to pointing to another file elsewhere.
  
* **Bright Red**: Archive/ Compressed File

  * Ex. `backup.tar.gz`, `setup.zip`
  
* **Regular (White/Black)**: Standard Text / Data File

  * Ex. `config.yaml`, `README.md`,`app.log`
